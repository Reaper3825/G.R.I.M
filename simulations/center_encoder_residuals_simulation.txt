PART 1: WHAT THE FIX DOES (exact mathematical definition)
════════════════════════════════════════════════════════════════════════════

Definition: Column centering
───────────────────────────────
  Given H ∈ ℝ^{n×d}  (n = num_tokens, d = d_model = 768):

    H_centered = P · H    where P = I_n − (1/n) · 1_n · 1_n^T

  Per-element:
    h_centered[t, d] = h[t, d] − (1/n) Σ_s h[s, d]

  Effect: For each feature dimension d, the mean across positions is set to zero:
    Σ_t h_centered[t, d] = 0    for all d ∈ {1, ..., 768}


Where it is applied (in Encoding_GPU.cu):
───────────────────────────────────────────
  Standard pre-norm encoder layer:
    residual1 = input + LS1 · Attn(RMSNorm(input))          ← Step 7
    residual2 = residual1 + LS2 · FFN(RMSNorm(residual1))   ← Step 10

  WITH center_encoder_residuals=true:
    residual1 = center_columns(input + LS1 · Attn(RMSNorm(input)))       ← Step 7
    residual2 = center_columns(residual1 + LS2 · FFN(RMSNorm(residual1)))← Step 10

  Total centering operations per forward pass: 2 × 12 layers = 24.

PART 2: HOW CENTERING AFFECTS ρ — ALGEBRAIC PROOF
════════════════════════════════════════════════════════════════════════════

§2.1 Decomposition of hidden states into shared + unique components
───────────────────────────────────────────────────────────────────

  Any set of hidden states h(1), ..., h(n) can be decomposed:
    h(t) = μ + δ(t)     where μ = (1/n) Σ_t h(t),  Σ_t δ(t) = 0

  The pairwise cosine is:
    cos(h(i), h(j)) = (μ + δ(i)) · (μ + δ(j)) / (‖h(i)‖ · ‖h(j)‖)
                     = (‖μ‖² + μ·δ(j) + δ(i)·μ + δ(i)·δ(j)) / (‖h(i)‖ · ‖h(j)‖)

  When ‖μ‖ is large relative to ‖δ(t)‖:
    cos(h(i), h(j)) ≈ ‖μ‖² / ‖h‖² + O(δ/‖h‖)

  This is the ρ we measured growing from 0.05 → 0.44.


§2.2 What centering removes
────────────────────────────

  After centering:
    h_centered(t) = h(t) − μ = δ(t)

  Therefore:
    cos(h_c(i), h_c(j)) = δ(i) · δ(j) / (‖δ(i)‖ · ‖δ(j)‖)

  The ‖μ‖² term is GONE. The remaining ρ depends only on the correlation
  of the position-specific deviations δ(t), which are uncorrelated with
  the shared component.


§2.3 Quantitative prediction: ρ after centering
────────────────────────────────────────────────

  From measured data at B90 (before centering):
    ρ(final) = 0.237
    PC1_var  = 33.6%

  The shared component (PC1) contributes approximately:
    ρ_from_PC1 ≈ PC1_var = 0.336   (upper bound, actual ρ depends on projection angles)

  After centering removes PC1:
    ρ_remaining ≈ ρ − PC1_contribution

  More precisely, the centering projection removes ANY direction that is
  constant across positions. PC1 is the dominant such direction.
  Column centering removes ALL shared directions simultaneously (not just PC1).

  PREDICTION: After centering, ρ(layer_output) ≈ ρ(layer_input)
  because the newly-created shared component is zeroed at each layer.

  At B90 measured: ρ(emb) = 0.064. With centering at every layer:
    ρ(final) ≈ ρ(emb) + noise ≈ 0.04 − 0.07    (instead of 0.237)

§3.3 Why each layer's Δρ becomes ~0
────────────────────────────────────

  At layer l without centering, the residual sum creates shared direction μ_l:
    h^l(t) = h^{l-1}(t) + LS · f(RMSNorm(h^{l-1}(t)))
    μ_l = (1/n) Σ_t h^l(t) = μ_{l-1} + LS · (1/n) Σ_t f(RMSNorm(h^{l-1}(t)))

  The second term adds a new shared component. Without centering, this
  ACCUMULATES: μ_l = μ_0 + Σ_{k=1}^{l} δμ_k.

  With centering:
    h^l_centered(t) = h^l(t) − μ_l
    → μ_l^{after_centering} = 0    (by definition)

  At layer l+1:
    h^{l+1}(t) = h^l_centered(t) + LS · f(RMSNorm(h^l_centered(t)))
    μ_{l+1} = 0 + LS · (1/n) Σ_t f(RMSNorm(h^l_centered(t)))

  μ_{l+1} is ONLY the contribution from THIS layer's sublayer, not accumulated.
  Centering then removes this too. The shared direction never compounds.

PART 5: GRADIENT COST OF CENTERING — IS IT SAFE?
════════════════════════════════════════════════════════════════════════════

§5.1 Backward pass of center_columns
─────────────────────────────────────

  Forward:  h̃ = P · h    where P = I − (1/n) · 1·1^T

  Backward: ∂L/∂h = P^T · ∂L/∂h̃ = P · ∂L/∂h̃    (P is symmetric)

  The centering projection P has eigenvalues:
    λ = 0   (multiplicity 1: the constant vector 1/√n)
    λ = 1   (multiplicity n−1: all directions orthogonal to 1)

  The gradient in the constant direction is zeroed (1 dimension lost).
  The gradient in all other n−1 dimensions is preserved EXACTLY.


§5.2 Per-layer gradient attenuation
────────────────────────────────────

  Fraction of gradient variance preserved per centering operation:
    (n − 1) / n = (6000 − 1) / 6000 = 0.999833

  Over 24 centering operations (2 per layer × 12 layers):
    Total preservation = ((n−1)/n)^24

  For typical batch sizes (n = total_tokens):
    n = 4000:  (3999/4000)^24 = 0.99402  → loses 0.6% of gradient signal
    n = 6000:  (5999/6000)^24 = 0.99601  → loses 0.4% of gradient signal
    n = 8000:  (7999/8000)^24 = 0.99700  → loses 0.3% of gradient signal
    n = 8192:  (8191/8192)^24 = 0.99707  → loses 0.3% of gradient signal

  MEASURED: Session used max_tokens_per_batch = 8192 with batch_size = 8.
  Typical valid_tokens per batch: 6306 − 7453 (Table from equation log).

  At n = 7000: (6999/7000)^24 = 0.99657 → loses 0.34% of gradient signal.


§5.3 Comparison to existing gradient overhead
──────────────────────────────────────────────

  Current gradient overhead from other operations:
    Dropout (p=0.125):  scales gradients by 1/(1−p) = 1.143 (14.3% amplification!)
    Dropout (attn, p=0.2): scales by 1/(1−p) = 1.25 (25% amplification)
    RMSNorm backward:   Jacobian has eigenvalues in [0, 1] (can attenuate up to 100%)
    LayerScale (LS=1):  1× passthrough (no attenuation)

  Centering cost of 0.3% is TWO ORDERS OF MAGNITUDE smaller than dropout's
  14% amplification, and negligible compared to RMSNorm's variable attenuation.

  VERDICT: The gradient cost is not just acceptable — it is insignificant.

PART 6: WHAT CENTERING DOES NOT AFFECT
════════════════════════════════════════════════════════════════════════════

Centering is a linear projection. It does NOT change:

  1. Per-token norms (RMS):
     ‖h̃(t)‖² = ‖h(t) − μ‖² ≤ ‖h(t)‖²
     Norms can decrease slightly but the direction is what matters for ρ.
     Measured h_rms ≈ 0.96 throughout — this stays approximately the same.

  2. Sublayer computations:
     RMSNorm1(h) normalizes each row independently → not affected by cross-position mean.
     Attention Q/K/V and FFN operate per-row → no coupling to the mean.
     (Attention operates across positions, but the mean is removed from the
      RESIDUAL STREAM, not from the normalized Q/K/V inputs.)

  3. Weight magnitudes:
     W_rms[36] = 0.0243 comes from Xavier init + AdamW updates.
     Centering doesn't touch weights, only hidden states.

  4. Embedding ρ:
     ρ(emb) comes from shared BOS tokens and overlap between training sequences.
     Centering is applied AFTER embedding → ρ(emb) unchanged.

  5. Loss function:
     cross_entropy(logits, targets) is unchanged.
     Centering changes the INPUTS to the logit computation, not the loss formula.
     The logits become more diverse → loss decreases (prediction).

§8.2 Why LR reduction is a band-aid
────────────────────────────────────

  LR controls the step size: W_new = W - lr · g / √(v + ε)

  The ρ growth rate is Δρ/Δstep ∝ lr × (attention-induced shared component).
  Reducing lr by K× slows ρ growth by K×, but:
    • Also slows learning by K×
    • Eventually ρ STILL accumulates to dangerous levels (just takes K× longer)
    • The gradient inversion crossover still occurs at the same ρ value (~0.10)

  LR reduction delays collapse. Centering prevents it.


§8.3 Why centering at LM head only is insufficient
───────────────────────────────────────────────────

  project_out_pc1 at the LM head (current config):
    h̃(t) = h(t) − (h(t)·g)g    where g = PC1(H)

  This removes PC1 from the FINAL hidden states before logit computation.
  But the INTERNAL encoder layers (L0-L11) still see correlated inputs:
    • L8's attention operates on ρ=0.200 input (B90)
    • Its Q/K projections produce correlated attention scores
    • Its V averaging creates MORE shared output
    • This feeds L9, amplifying further

  LM head centering is a band-aid that treats the output.
  Encoder centering prevents the disease from developing.
