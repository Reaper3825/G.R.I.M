# After editing this file, re-run scripts/setup_mobileclip.py to rebuild
# resources/models/vision/mobileclip_text_embeddings.bin so the C++ side
# picks up the new label set.
#
# Tips:
#   - Use full natural-language phrases ("a photo of ...") — CLIP was
#     trained on web captions and scores those better than bare nouns.
#   - Add an explicit "negative / catch-all" row so unrelated frames have
#     somewhere to land instead of forcing one of the real labels.
#   - Keep the list focused (~20–60 prompts). Larger lists dilute scores.
#
