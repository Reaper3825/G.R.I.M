✅ **SCRATCH BUFFER OPTIMIZATION - LOSS COMPUTATION**:
  **Status**: Production-ready optimization eliminating malloc/free overhead
  **Problem Identified**: 
    - cudaMalloc/cudaFree called for EVERY sequence in computeLoss()
    - With GPU memory exhausted (0 MB free), each malloc took 1-2 seconds to defragment/evict
    - Each cudaFree forced GPU synchronization, adding 1-2 seconds
    - Math: 4 sequences × (2 mallocs + 2 frees) × 2 sec = 32+ seconds per batch
    - Training was UNUSABLE: 30-60 seconds per step (would take 7-15 hours for minimal training)
  **Solution Implemented**:
    - Added scratch buffers to TrainingState struct (grim_language_model_cuda.hpp lines 687-750):
      ```cpp
      float* d_loss_scratch = nullptr;       // Per-token losses buffer
      float* d_loss_sum_scratch = nullptr;   // Reduced loss sum buffer
      size_t loss_scratch_capacity = 0;      // Current allocation size
      ```
    - Modified computeLoss() to reuse buffers (grim_language_model_gpu.cu lines 892-985):
      - Removed cudaMalloc/cudaFree from hot path (was called per sequence)
      - Pre-allocate buffers once, reuse across all sequences
      - Only reallocate if sequence exceeds current capacity
      - Eliminates 16 GPU synchronization points per batch
  **Performance Impact**:
    - Before: 30-60 seconds per step, 0 MB GPU free (memory exhaustion)
    - After: 0.5 seconds per step, 3366 MB GPU free
    - Speedup: 60-120× faster (from unusable to production-ready)
    - Example timing: 17 steps in 8 seconds (13:49:20 → 13:49:28)
  **Testing Results**:
    - ✅ Training viable at ~0.5 sec/step (was 30-60 sec/step)
    - ✅ GPU memory freed: 0 MB → 3.3 GB free
    - ✅ Loss decreasing correctly: 7.108 → 7.089
    - ✅ No memory leaks with buffer reuse
    - ✅ No race conditions observed
  **Code Locations**:
    - Struct definition: grim_language_model_cuda.hpp lines 687-750
    - computeLoss() optimization: grim_language_model_gpu.cu lines 892-985
    - computeLossBatch() (still sequential): grim_language_model_gpu.cu lines 987-1019
  **Remaining Optimization Potential**:
    - ⚠️ Training still processes sequences sequentially (not true batched forward pass)
    - Could achieve additional 4-8× speedup with full batched implementation
    - Current solution makes training viable; batching optimization is future enhancement
  **Root Cause Analysis**:
    - Primary bottleneck: Memory allocation in hot path with exhausted GPU memory
    - Why so slow: cudaMalloc must defragment, cudaFree must synchronize
    - Solution: Move allocations out of loop, reuse same buffers
  **Date**: November 13, 2025 13:49:28

    - **PROBLEM DIAGNOSED**: Weight initialization variance correction (0.87×) was COLLAPSING activation variance!
      * Applied 0.87× correction thinking weights were 10-25% too large
      * Result: Forward pass variance collapsed from var≈1.0 to var≈0.0004 (2500× too small!)

      * Original weight initialization was CORRECT (Xavier/Glorot)
      * Variance measurements showing "10-25% too large" were actually HEALTHY
      * Box-Muller transform with LCG produces proper normal distribution
      * No correction factor needed - removed the 0.87× multiplier
    
    - **THE FIX** (grim_training_kernels.cu, lines 670-679):
    ```cpp
    __device__ float normal_random(unsigned int* seed, float mean, float stddev) {
        float u1 = lcg_random(seed);
        float u2 = lcg_random(seed);
        u1 = fmaxf(u1, 1e-8f);
        float z0 = sqrtf(-2.0f * logf(u1)) * cosf(2.0f * 3.14159265359f * u2);
        return mean + stddev * z0;  // NO correction factor - Box-Muller is correct!
    }
    ```

    1. **CUDA Kernel** (grim_training_kernels.cu, lines ~20-60):
    ```cpp
    __global__ void clampGradientsKernel(
        float* gradients,
        int n,
        float min_val,
        float max_val)
    {
        int idx = blockIdx.x * blockDim.x + threadIdx.x;
        
        if (idx < n) {
            float val = gradients[idx];
            
            // Clamp to range [min_val, max_val]
            // Also handles inf/-inf by clamping to finite bounds
            if (val < min_val || !isfinite(val)) {
                gradients[idx] = min_val;
            } else if (val > max_val) {
                gradients[idx] = max_val;
            }
        }
    }
    
    void launchClampGradients(
        float* gradients,
        int n,
        float min_val,
        float max_val,
        cudaStream_t stream)
    {
        int block_size = 256;
        int grid_size = (n + block_size - 1) / block_size;
        
        clampGradientsKernel<<<grid_size, block_size, 0, stream>>>(
            gradients, n, min_val, max_val
        );
        
        cudaError_t err = cudaGetLastError();
        if (err != cudaSuccess) {
            fprintf(stderr, "CUDA error in launchClampGradients: %s\n", 
                    cudaGetErrorString(err));
        }
    }
    ```

  auto val_dynamic_batches = createDynamicBatches(val_seqs, batch_size);
  
  float val_loss = 0.0f;
  int val_sequences_processed = 0;
  
  for (int val_idx = 0; val_idx < val_dynamic_batches.size(); ++val_idx) {
      const auto& val_dyn_batch = val_dynamic_batches[val_idx];
      
      // Construct validation batch from dynamic batch indices
      std::vector<std::vector<int>> val_batch_inputs;
      std::vector<std::vector<int>> val_batch_targets;

          val_batch_inputs.push_back(val_seqs[idx].token_ids);
          val_batch_targets.push_back(val_seqs[idx].targets);
      }
      
      // Compute batch validation loss
      float batch_val_loss = model->computeLossBatch(val_batch_inputs, val_batch_targets);
      val_loss += batch_val_loss * val_dyn_batch.effective_batch_size;
      val_sequences_processed += val_dyn_batch.effective_batch_size;
  }
  val_loss /= val_sequences_processed;
  
  // Calculate perplexity

  logger.log("Validation Loss: " + std::to_string(val_loss) + 
             " | Perplexity: " + std::to_string(perplexity));
